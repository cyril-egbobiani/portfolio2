<Section id="problem" label="The problem" title="Rebuilding a design language meant eyedropping one hex code at a time">

Recreating someone else's design language usually means eyedropping it one hex code at a time and manually calculating font scales.

</Section>

<Section id="solution" label="Solution" title="Read the tokens straight from the page's computed styles">

The extension parses a page in real time and extracts its tokens — colours, shadows, typography, and spacing — into clean JSON or CSS variables.

<Insights>
<Insight label="01" title="Tokens from any live page">
Extracts colours, shadows, fonts, and layout tokens directly from the page's DOM.
</Insight>
<Insight label="02" title="Ready to paste">
Copy tokens straight into CSS variables or Tailwind token formats.
</Insight>
